# Demo: Web Calculator

Build a minimal web-based calculator using vanilla HTML, CSS, and JavaScript.

## Requirements

- Basic operations: add, subtract, multiply, divide
- Clear button (C) and equals button (=)
- Decimal point support
- Display shows current input and result
- Keyboard input support (0-9, +, -, *, /, Enter, Escape, Backspace)
- Error handling for division by zero

## Technical constraints

- Single HTML file (`calculator.html`) with inline CSS and JS
- No external dependencies or frameworks
- Responsive — works on mobile and desktop
- Clean, modern UI (dark theme preferred)

## Acceptance criteria

- Open `calculator.html` in a browser, perform `2 + 3 = ` and see `5`
- Division by zero shows "Error" instead of crashing
- Keyboard shortcuts work (Enter = equals, Escape = clear)
- Layout looks reasonable on a 375px-wide screen
